# Native2dAnalyzer 代码审查记录（2026-10-07）

## 范围

切片 3：`native_analyzer.hpp/.cpp`、分析器测试、`GeometryDocument` 的逐实体警告入口，以及状态文档同步。不包含 DXF、Qt、CDR、OCC 或拓扑修复。

## 关键设计核对

- `src/core/**` 仅使用 C++ 标准库和项目自有类型；
- 非恒等变换不参与求值，按原始几何统计并告警；
- 圆弧包围盒只包含起终点和实际扫角经过的基数方向；
- 非有限坐标、非正半径和不可表示结果不会污染总长或包围盒；
- 空几何与坏几何分开处理：空折线/零扫角圆弧是零指标，坏数据产生警告；
- 文档与逐实体警告按稳定顺序汇总，逐实体指标保留 `hasWarning`。

## 审查中修复

1. MSVC 对 `if constexpr` 后的公共 `return` 报不可达代码；改为显式 `else`，恢复 `/WX` 零警告。
2. 文档模型没有合法入口写入 `GeometryEntity::warnings`；给 `add()` 增加末尾可选参数，保持旧调用兼容并补测试。
3. 在分析器层补极小正扫角回归，避免紧凑包围盒重新引入 epsilon 丢弧问题。
