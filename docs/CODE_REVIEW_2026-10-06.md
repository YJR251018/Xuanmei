## 已修复问题

### 1. 有效的极小圆弧会被静默当成零长度

- 严重度：中
- 位置：`src/core/entity.cpp`
- 原因：实现用 `1e-12°` epsilon 判断退化圆弧，与“只有零扫角退化”的接口约定不一致。
- 影响：扫角在 `(0, 1e-12°]` 内的合法实体丢失长度，后续总长和加工轨迹会偏小。
- 修复：只把精确零扫角视为退化；新增 `5e-13°` 回归用例。

### 2. `GeometryDocument::add()` 异常时会消耗 ID

- 严重度：中
- 位置：`src/core/document.cpp`
- 原因：`nextId_` 在 `vector::push_back` 成功前递增。
- 影响：若分配或移动抛异常，下一次成功添加会跳号，违反连续 ID 契约。
- 修复：先成功写入实体，再递增计数器；返回保存的 ID。

### 3. 公共头文件依赖传递包含

- 严重度：低
- 位置：`src/core/document.hpp`
- 原因：内联 `std::move` 未直接包含 `<utility>`。
- 修复：补齐直接依赖；`unit()` 继续按设计契约返回值，避免调用方持有会被 `setUnit()` 失效的引用。

### 4. 仓库同时维护两套技术栈且状态文档失真

- 严重度：维护风险
- 原因：根目录 Python 原型、临时验证 UI 与 C++ 正式实现并存；README 仍声称 C++ 工具链和正式工程不存在。
- 修复：删除 Python/UI 原型和临时报告，统一为 C++ 主线；同步 README、设计、ADR 与开发流程。
