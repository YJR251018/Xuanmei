# 架构决策记录

本文件记录会影响后续实现的重要决定。新决定按时间追加，不覆盖历史内容。

## ADR-001：使用独立的内部几何模型

- 状态：已接受
- 日期：2026-10-05

### 决定

在 libcdr、DXF、OpenCASCADE 和 Qt 之间建立项目自有的 `GeometryDocument`，所有第三方格式先转换到该模型。

### 原因

- 隔离第三方库接口变化；
- 便于测试格式转换误差；
- 允许替换 DXF 或 CDR 后端；
- 避免界面代码承担格式解析职责。

## ADR-002：第一阶段实现最小 DXF Writer

- 状态：已接受
- 日期：2026-10-05

### 决定

第一阶段自行实现项目所需的 ASCII DXF 输出子集，不直接链接 GPL 许可的 libdxfrw。

### 原因

- 第一阶段只需少量二维实体；
- 更容易控制曲线映射和单位；
- 避免过早确定整个项目的许可证；
- libdxfrw 仍可用于行为参考和独立交叉验证。

## ADR-003：OCCT 不负责默认 DXF 导入

- 状态：已接受
- 日期：2026-10-05

### 决定

OpenCASCADE 用于几何、拓扑和容差分析，不作为默认 DXF 读取后端。

### 原因

开源 OCCT 本体没有可直接依赖的免费 DXF 数据交换组件。将格式读写与几何计算分开也更符合项目模块边界。
